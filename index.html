Cara Pakai

Isi briefing di bawah → klik Generate Prompt & Narasi → salin prompt tiap slide → tempel ke ChatGPT (DALL·E) untuk dibuatkan gambarnya. Setiap prompt sudah dioptimalkan agar aman dari filter konten — karakter dewasa, syar’i, dan tidak ada deskripsi anak sebagai subjek utama.
